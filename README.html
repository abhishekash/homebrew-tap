Agenturm Homebrew tap

Install the Rust 0.3.16 binary bundle with Homebrew:

brew install abhishekash/tap/agenturm

Supported systems are Apple Silicon Macs running macOS 13 or later and Linux (glibc 2.39+) on x86_64 or aarch64. Intel Macs are not supported.

The full bundle remains together under Homebrew’s libexec, so Agenturm can find its plugin host, harnesses, and catalog. Installation and runtime do not require Python or a Rust toolchain.

Build from source

brew install abhishekash/tap/agenturm-source

The source alternative builds the immutable Rust 0.3.11 archive with locked Cargo dependencies, macOS system SQLite on Mac, and Homebrew SQLite on Linux. Homebrew installs Rust and pkgconf for the build. Python is not required. Uninstall the binary formula before installing the source formula, because they provide the same commands. Update with brew upgrade agenturm-source.

CI covers binary installs and source builds on Apple Silicon, Linux x86_64, and Linux ARM64, including functional discovery and collection, shared SQLite linkage, style, strict new-formula audit, livecheck, bottle reinstallation, and repeat checksum regeneration.

Homebrew core submission

core-candidate/agenturm.rb contains the source formula under its proposed core name. A fresh brew install agenturm requires acceptance into Homebrew core. Until then, use the fully qualified tap command above. See Homebrew’s public-interest requirements. Homebrew requires human review of AI-assisted submissions and human-written responses to maintainer feedback.

The Homebrew core readiness workflow (on candidate PRs or manual dispatch) stages the candidate in a real core checkout and runs strict new-formula audit. Core acceptance failures are reported separately from tap validation.

Update

brew update
brew upgrade agenturm

Quit older Agenturm processes before launching 0.3.16. Its first writer open builds history indexes and upgrades to schema 28; older versions cannot read the upgraded store. Large histories can take longer to open initially.

Uninstall

brew uninstall agenturm
